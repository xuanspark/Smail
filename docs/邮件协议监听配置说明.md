# 邮件协议监听配置说明

## 配置入口

进入“设置 → 配置管理”，分别打开 SMTP 配置、IMAP 配置、POP3 配置。

| 配置页面 | 监听用途 | 默认端口 |
| --- | --- | --- |
| SMTP 配置 | 接收邮件，支持 STARTTLS | 25 |
| SMTP 配置 | 客户端提交，使用 STARTTLS | 587 |
| SMTP 配置 | 隐式 TLS | 465 |
| IMAP 配置 | 隐式 TLS | 993 |
| POP3 配置 | 使用 STLS 升级加密 | 110 |
| POP3 配置 | 隐式 TLS | 995 |

SMTP 页面中的发信中继是外部服务器连接配置，与本机监听端口无关。IMAP 当前仅提供隐式 TLS，不提供明文或 STARTTLS 监听。

“邮箱策略”自动读取这三个页面的已应用端口，不能再单独修改端口。该汇总不是在线检测，也不展示尚未应用的候选端口。

## 保存与生效

1. 修改对应协议端口，完成近期登录认证并验证配置。
2. 保存候选后核对内容，再应用配置。
3. 根据待重启提示重启后端，使新监听端口生效，并同步调整客户端、反代或防火墙。

IMAP、POP3、邮箱策略是独立页面，但共用邮箱配置分区。候选会提示涉及哪些页面，需要逐页核对；应用时该分区一起生效。配置端口不能与其他邮件监听或 Web 监听冲突。

## 存储与旧配置兼容

- SMTP 监听保存在 SMTP 分区的 `listener`，不覆盖 `relay`。
- IMAP、POP3 分别保存在邮箱分区的 `imap`、`pop3`，保留 `policy`。
- 未配置新 SMTP 收信端口、POP3 STLS 端口时，兼容旧策略端口；未配置其他端口时采用表中默认值。零值表示兼容默认，不表示禁用服务。
- 旧 `policy.imapPort` 从未控制实际监听，保留该字段但不把原有 TLS 端口从 993 自动迁移到 143。
- 保持原有配置分区文件结构，无需新增独立 IMAP、POP3 配置文件。
