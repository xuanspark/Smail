### R01 / P1：迁移成功切库，但自定义唯一索引静默丢失

- 位置：`backend/services/dbmigration/portable_schema.go:9-28`；`portable_executor.go:177-223`；`portable_data.go:72-95,111-117`。
- 前提：源库包含版本化表之外的自定义唯一索引。
- 原因：源对象校验未识别这些索引，目标库按内置结构重建，之后只验证数据，不验证自定义约束等价性。
- 实测：完整版本化 SQLite 源库增加唯一索引后执行迁移，结果为 `switched=true custom_index_count=0 duplicate_insert_error=<nil>`。
- 影响：迁移被报告成功，但源库禁止的重复值可以写入目标库。
- 建议：无法忠实迁移的结构在预览和执行时明确拒绝，或完整迁移并比较索引、约束。
- 边界：只实测 SQLite，不将结果泛化为三种数据库实库均已验证。
- 复现：`TestAuditCustomUniqueIndexMustNotDisappear`。

### R02 / P1：登录二次验证重发接口错误要求先登录

- 位置：`backend/listen/http_server/https_server.go:168-170,194-200`；`api_v1_compat.go:19`；`http_server.go:52`；`frontend/src/views/LoginVerification/LoginVerification.js:93-103`。
- 前提：密码已验证，但尚未完成登录二次验证，用户需要重发验证码。
- 原因：登录前安全接口白名单遗漏 `/api/v1/security/login/resend`，请求未到验证码控制器就被登录拦截。
- 实测：真实路由、内存会话返回 HTTP 200，响应体业务码 403：`Login has expired.`。
- 影响：未登录用户无法在二次验证页重发验证码。
- 建议：将该接口归入登录前安全路由，保留挑战票据、限频及 CSRF 等校验。
- 边界：未发送真实验证码；不能据此断言前端必然跳回登录页。
- 复现：`TestAuditAnonymousLoginResendMustReachController`。

### R03 / P2：迁移排空请求不响应取消

- 位置：`backend/services/dbmigration/maintenance.go:62-70`；`service.go:224-232`。
- 原因：持有或升级请求租约时使用不可取消的 `RWMutex.Lock()`，传入的上下文未参与等待。
- 实测：30ms 上下文超时，200ms 后仍未退出，必须释放在途读锁才恢复。
- 影响：在途请求长期不结束时，迁移取消/超时不能及时结束排空，还可能让新 HTTP 请求排队等待。
- 建议：采用可取消的排空协调方式，确保请求租约、迁移状态和错误路径一致释放。
- 边界：证明的是超时不生效，不是已经复现永久死锁。
- 复现：`TestAuditRequestDrainMustRespectCancellation`。

### R04 / P2：邮件列表第二页起返回总数 0

- 位置：`backend/services/list/list.go:28-30,98-107`；`backend/controllers/email/list.go:120-129`。
- 原因：聚合计数查询错误附带分页偏移和排序。
- 实测：31 封邮件，每页 15 封；偏移 0/15/30 分别返回行数 15/15/1，总数却为 31/0/0。

- 复现：`TestAuditPaginationMustPreserveTotal`。

### R05 / P1：撤销安全密钥后，旧恢复票据仍允许改密

- 位置：`backend/services/recovery/service.go:315-328,390-417`；`backend/services/webauthn/service.go:323-333`。
- 前提：安全密钥验证后已签发恢复票据，随后该凭据被撤销，票据仍未过期。
- 原因：恢复完成阶段只对邮箱来源重新检查凭据；WebAuthn 来源没有同等撤销检查。
- 实测：真实撤销凭据后，旧票据完成改密返回成功，并用密码校验函数确认新密码生效。
- 影响：用户撤销凭据后，先前依赖该凭据产生的改密授权仍有效到票据过期。
- 建议：完成改密时重新校验票据所绑定的凭据归属、撤销状态及版本，或撤销时使关联票据失效。
- 边界：隔离测试从签发恢复票据阶段开始，不验证真实设备的 WebAuthn 签名链；不是未认证直接获取票据的证明。
- 复现：`TestAuditRevokedWebAuthnMustInvalidateRecoveryTicket`。
