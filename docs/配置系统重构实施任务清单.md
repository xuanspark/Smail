## 2. 状态和执行规则

### 2.1 状态枚举

| 状态 | 含义 |
|---|---|
| 未开始 | 尚未进入实施 |
| 进行中 | 正在编码或验证 |
| 待复审 | 实施和自测完成，等待独立安全复审 |
| 已完成 | 验收条件全部满足并留存证据 |
| 阻塞 | 存在明确外部依赖，无法继续 |

### 2.2 优先级

| 优先级 | 含义 |
|---|---|
| P0 | 安全边界或后续任务前置条件，必须优先完成 |
| P1 | 核心功能，阻塞阶段验收 |
| P2 | 完整性、体验或运维增强 |

### 2.3 标记规则

任务从“未开始”变更为“已完成”前，必须同时满足：

1. 实施步骤全部完成；
2. 安全要求全部通过；
3. 自动化测试通过；
4. 需要页面验证的任务完成真实浏览器验证；
5. 任务证据填写命令、结果和关键文件；
6. 不存在未说明的失败测试或平台缺口；
7. 经过复审后由“待复审”改为“已完成”。

### 2.4 全局限制

1. 不使用 Docker；
2. 不将真实密码、Token、DSN 或密钥写入仓库和测试日志；
3. 不引入旧弱算法或验证失败后的旧算法回退；
4. 不允许插件读取主配置、临时构造的数据库 DSN、数据库配置或访问主数据库；
5. 不允许仅通过前端隐藏按钮实现权限控制；
6. 不删除旧文件、旧数据库列或旧接口，除非另行获得用户明确许可；
7. 修改源代码后执行格式化、单元测试、集成测试和安全测试；
8. 文档、注释、说明和界面文字使用中文，代码标识符使用简洁英文；
9. 文本文件保持 UTF-8 无 BOM；
10. 提交和推送不属于本清单默认动作，需要用户另行指示。

### 2.5 跨文档依赖与任务归属

本清单使用 `CG-001`～`CG-057` 管理配置系统重构总体任务；`docs/超级管理员重置与邮箱验证码实施任务清单.md` 使用 `AD-001`～`AD-066` 管理超级管理员部署端重置和完整邮箱验证码的详细任务。两份清单共同构成本轮正式开发范围，执行规则如下：

## 15. 发布阻塞条件

出现以下任一情况，不允许将本轮重构标记为完成或进入生产发布：

1. 存在未关闭的 P0 或 P1 安全漏洞；
2. 配置文件仍可能明文保存数据库、SMTP 或插件 Secret；
3. 仍存在通过旧算法或弱恢复方式绕过验证的路径；
4. 用户名和完整邮箱在不同协议中的认证结果不一致；
5. 管理员或普通用户可以越权修改不允许的插件配置；
6. 恢复码可以重复查看、重复使用或并发双花；
7. WebAuthn 未完整校验 Challenge、Origin、RP ID、签名和用户归属；
8. 超级管理员密码恢复能力可通过 TCP、普通 Web 页面或公共 API 访问；
9. 插件可以读取主配置、数据库 DSN、主数据库或其他插件配置；
10. 配置事务中断后可能以混合代次启动；
11. 前端、日志、审计或错误响应泄露 Secret、恢复码或票据；
12. 测试失败、跳过项或未验证平台没有明确记录；
13. 未经用户许可删除了文件、旧配置或数据库列；
14. 超级管理员可以通过 Web 修改或恢复自己的密码；
15. 普通用户可以访问含目标用户 ID 的跨用户插件设置接口；
16. 批量插件设置可以跳过预览、重放预览票据或静默覆盖用户个性化配置；
17. 管理员可以启停插件或重启未明确授权的插件实例；
18. 超级管理员本地维护会话可以重复使用、跨进程复用或从参数、环境变量、日志和长期配置中获得；
19. 外部安全邮箱验证码关闭、未通过安全验收或配置无效时仍可以形成可用恢复路径；
20. 超级管理员重置密码后目标用户的旧 WebAuthn、恢复码、Session、恢复流程或票据仍然有效；
21. 数据库名称迁移可以跨类型、跨服务器、跨账户执行，失败后切断旧数据库，或自动删除旧数据库；
22. 配置审计可被普通 Web API 删除、保留不足 365 天、导出未脱敏或导出行为未审计；
23. Web 重启接口可以接收或执行客户端提交的命令、脚本、参数或服务名；
24. 插件 Secret 明文进入文件、日志、审计或配置备份，或主加密密钥与密文存放在同一数据库；
25. 插件可绕过目标主机、端口和协议白名单，或未经能力授权使用 Web Push；
26. 超级管理员部署端固定重置服务、专用重置通道、Windows Named Pipe、Unix Domain Socket 平台适配器或相关安全测试未完成；
27. 完整邮箱验证码服务、SMTP 投递、登录邮箱二次验证、外部邮箱密码恢复、外部邮箱管理页面、运营数据或每 14 天定期清理任一项未完成；
28. Linux 正式入口不是唯一的 `systemctl start smail-admin`，或密码可经参数、标准输入输出、环境变量、文件、服务名或日志传递；
29. 密码重置权限不符合“超级管理员重置管理员和普通用户、管理员重置普通用户、普通用户仅重置本人、部署端仅重置超级管理员自身”；
30. AD-066 尚未完成独立清单最终发布评审或未向 CG-057 提供聚合验收证据。

完成上述 57 项任务并通过 30 项发布阻塞条件检查后，才能将配置系统重构进入最终发布评审。
