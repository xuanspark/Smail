- SMTP 中继选择加密方式后自动填写端口，不要求用户记忆常用端口。
- 网页加密方式联动内置 HTTPS 开关和端口，反代模式继续停用 Smail 自动证书签发与续期。
- 读取配置不覆盖自定义端口；SMTP 主动切换加密方式后填写推荐值，允许再次手动调整。
- 使用可视化表单，不新增 JSON 编辑入口，不修改当前业务数据库或邮件数据。
- 重新编译并运行项目，确认实际运行的是更新后的前端。

## 配置规则

| 配置方式 | 推荐端口 | 行为 |
| --- | --- | --- |
| SMTP STARTTLS | 587 | 主动切换时自动填写 |
| SMTP 隐式 TLS / TLS 兼容模式 | 465 | 主动切换时自动填写 |
| SMTP 本机不加密 | 25 | 仅限回环地址；远程明文拒绝通过校验 |
| 内置 HTTPS | 443 | 自动开启内置监听；缺少端口时补全，保留有效的自定义端口 |
| 内置模式 HTTP | 80 | 缺少端口时补全 |
| 反代模式 HTTP | 8080 | 缺少端口时补全；已有监听端口不强制修改，HTTPS 端口归零 |

一键使用推荐端口只修改当前草稿，仍需完成校验、保存候选与应用流程。它不会立即重启服务，也不会更改反代服务器的配置。

邮件服务端口与 SMTP 中继端口不是同一组设置。本次不把收信端口 25 替换为客户端提交端口 465/587，也不把已有固定 TLS 监听伪装成可切换的加密模式。
