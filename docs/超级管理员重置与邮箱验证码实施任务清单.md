### 2.4 全局安全限制

1. 不使用 Docker；
2. 密码、验证码、验证码校验值、进程临时密钥、维护凭据、恢复授权、恢复码和 WebAuthn 私密数据不得进入日志；
3. 验证码任务及其 HMAC 校验值不得进入数据库、文件、Redis、消息队列、指标、追踪、审计详情或备份；
4. `smail-admin` 不读取数据库凭据、配置主密钥，不构造 DSN，不直接修改数据库；
5. 超级管理员自身密码不得通过普通 Web 页面、HTTP API、localhost TCP、公网或局域网 TCP 重置；
6. Linux 只允许 Unix Domain Socket，Windows 只允许 Named Pipe 作为部署端控制通道；
7. 密码统一使用主程序内经过评审的密码策略和 Argon2id 服务，不保留旧算法回退；
8. 邮箱验证码不能单独批准数据库迁移、配置回滚、角色变更、重置其他用户密码等高风险操作；
9. 功能关闭、SMTP 投递失败、服务重启或数据异常时必须安全拒绝，不允许降级绕过；
10. 中文文档、注释、说明和界面文字使用中文，代码标识符使用简洁英文；
11. 文本文件保持 UTF-8 无 BOM；
12. 提交和推送不属于本清单默认动作，需要用户另行指示。

## 3. 已确认实施基线

以下实施基线已经确认，后续任务不得重新引入旧冲突：

1. **正式开发范围**：完整实现验证码服务、SMTP 投递、登录邮箱二次验证、外部邮箱密码恢复、外部邮箱管理页面、运营数据和定期清理；
2. **Linux 正式入口**：唯一可写入口为 `systemctl start smail-admin`；`smail-admin` 是执行一次受控重置事务后退出的短时服务，不是常驻网络服务；
3. **安全密码交互**：使用 `systemd-ask-password` 或等效短时受保护本机凭据交互；无可用密码代理时安全拒绝，禁止参数、环境变量、文件、日志、标准输入和标准输出传递密码；
4. **权限矩阵**：超级管理员可重置管理员和普通用户，管理员只可重置普通用户，普通用户仅可重置本人，部署端 `smail-admin` 只可重置超级管理员自身；
5. **源码入口**：独立程序入口固定为 `server/cmd/smail-admin/main.go`；
6. **持久化边界**：验证码及校验值只存在于签发认证进程内存；非敏感运营数据允许持久化并每 14 天执行一次清理；
7. **验收边界**：systemd 安全交互、本机 IPC、Windows/Ubuntu 适配、三数据库、真实浏览器和安全负向测试均未完成前不得最终验收。

## 21. 发布阻塞条件

出现以下任一情况，不允许把本轮任务标记为完成或进入生产发布：

1. 正式入口不是唯一的 `systemctl start smail-admin`，或短时服务、安全密码代理模型被弱化；
2. 权限实现不符合“超级管理员重置管理员和普通用户、管理员重置普通用户、普通用户仅重置本人、部署端仅重置超级管理员自身”；
3. 超级管理员存在普通 Web 修改密码或公开忘记密码路径；
4. 超级管理员重置通道监听 TCP、注册 HTTP Router 或可由插件访问；
5. Linux Unix Domain Socket 或 Windows Named Pipe 任一平台未完成；
6. 本机 IPC 只依赖文件权限或 ACL，未验证调用者系统身份；
7. `smail-admin` 能读取数据库凭据、配置主密钥、构造 DSN 或直接修改数据库；
8. 密码能通过参数、环境变量、URL、配置文件、服务名、日志或标准输出传递；
9. 主程序和管理程序版本不兼容时仍可重置；
10. 重置会话能重复消费、跨进程复用或在主程序重启后继续有效；
11. 密码修改未使用统一 Argon2id 服务，或存在旧弱算法回退；
12. 超级管理员部署端重置后旧 Session、WebAuthn、恢复码、受信设备或票据仍有效；
13. 超级管理员强制重置其他用户时未按确认策略撤销安全凭据；
14. 验证码明文、密文、摘要、HMAC 校验值、任务或进程临时密钥进入任何持久化介质；
15. 验证码任务可在服务重启后恢复或通过外部存储跨实例共享；
16. 内存验证码没有容量上限、统一过期清理、错误阈值或原子单次消费；
17. 验证码可以跨用户、用途、邮箱、环境或凭据版本使用；
18. 密码错误时发送验证码，或验证码未通过时创建完整 Session；
19. 功能关闭、SMTP 失败或数据异常时可以降级绕过认证；
20. 管理员可以仅凭邮箱验证码恢复密码；
21. 超级管理员可以通过邮箱验证码恢复自己的密码；
22. 邮箱验证码可以单独批准高风险操作；
23. 公共恢复接口能够枚举账号、角色、邮箱绑定或投递结果；
24. 用户可越权读取或修改其他用户的外部邮箱、验证码或恢复事务；
