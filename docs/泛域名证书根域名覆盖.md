# 泛域名证书根域名覆盖

## 行为

项目托管证书选择 DNS 验证时，签发和续期统一申请主域名与对应泛域名。例如主域名为 `example.com` 时，证书包含 `example.com` 和 `*.example.com`。主域名由部署配置提供，不固定任何测试域名。

Web 地址允许使用主域名或一级子域名；多级子域名、其他主域名及超出覆盖范围的附加邮箱服务地址仍会被拒绝。

根域名与泛域名可能在同一 `_acme-challenge` 主机名生成不同的 TXT 值。页面展示全部记录，必须同时保留，不能把其中一条覆盖成另一条。清理一个挑战时只清理对应记录。

旧的仅泛域名证书缺少主域名覆盖，项目托管模式的证书检查会识别为覆盖不足，进入既有续期流程。手动及代理托管仍不自动续期。DNS 模式仍需要完成 TXT 设置；本次功能不新增 DNS 服务商凭据或外部续期脚本。

## 验证

- [x] 主域名与泛域名申请集合、空配置和大小写规范化回归。
- [x] 根域名与一级子域名可用，多级及无关域名拒绝。
- [x] 两条同名 TXT 独立保留与清理。
- [x] 真实 X.509 校验识别完整覆盖、缺少根域名、缺少泛域名。
- [ ] 云服务器真实 CA 签发及可信 TLS 验收。

本地回归通过不代表真实签发已完成；云端结果需另行记录。
