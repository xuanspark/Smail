## 3. 必须覆盖的安全负向矩阵

| 场景 | 预期结果 | 自动化入口 |
|---|---|---|
| 普通用户调用超级管理员重置 | 拒绝，不建立网络重置路径 | `services/adminreset` 授权测试 |
| HTTP 或 localhost TCP 触发超级管理员重置 | 不存在或拒绝 | HTTP 路由安全测试、部署审计 |
| 重放已消费 nonce | 拒绝 | `protocol_test.go`、传输测试 |
| 过期 nonce 或超时会话 | 拒绝 | SessionGuard 测试 |
| `--password`、密码环境变量或密码文件 | 拒绝 | 管理程序参数和密码代理测试 |
| 普通标准输入重定向 | 拒绝，不降级读取 | 密码代理平台测试 |
| 外部邮箱验证码关闭 | 不显示或不允许降级恢复 | 恢复 Controller 测试 |
| 错误验证码重复尝试 | 计数并限流 | verification service/store 测试 |
| 并发消费同一验证码或恢复码 | 只允许一次成功 | 并发测试和数据库事务测试 |
| 验证码跨账号、用途、资源或浏览器上下文复用 | 拒绝 | verification 绑定测试 |
| 超级管理员通过普通 Web 忘记密码 | 拒绝并引导本机通道 | reset entry 测试 |
| 重置后旧 Session、WebAuthn、恢复码和票据 | 全部失效 | credentials/recovery/webauthn 测试 |
| 审计、日志、响应、备份和浏览器存储出现敏感值 | 不得出现 | 敏感字段和泄露扫描 |
