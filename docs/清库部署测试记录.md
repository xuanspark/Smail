第一轮直接访问安装根地址出现“认证服务暂时不可用”。安装服务缺少 `/api/v1/user/info` 的初始化状态响应，前端未得到需要初始化的业务码。修复后，两个版本的认证探测路径均复用安装令牌和来源检查，只返回需要初始化状态，不执行账号或配置写入。

当前进程使用未提升的中等完整性令牌，管理员组仅用于拒绝检查。本机通道 ACL 仍限定 SYSTEM 与管理员，未放宽 ACL，未改成公开 HTTP 或 TCP 接口。
